# 大工课表 · Windows x64 开发预览

解压完整目录后运行 `DlutTimetable.Desktop.exe`，无需安装 .NET SDK 或 .NET Desktop Runtime。支持范围目前为已验证的 Windows 11 x64；Windows 10 的完整兼容性验收尚未完成。此包为未签名开发预览，不表示全部产品验收已完成。

也可运行 `Install.cmd`，按用户安装到 `%LOCALAPPDATA%\Programs\DLUTDesktopTimetable`，无需管理员权限。安装器先校验完整发布包，再等待原课表正常退出，切换版本并创建开始菜单及 Windows 已安装应用入口。初装默认登录启动；更新保留已关闭的偏好，不改 Windows 对启动项的外部禁用状态。安装管理窗口可恢复上一版本，课表与设置保持原位。正式发行签名及完整系统集成验收仍在实施。

已有独立数据目录时，可在安装窗口选择迁移来源。目标已有课表时拒绝覆盖；私人备注冲突也会停止。成功后来源目录保留，登录资料继续使用原有应用 profile，不复制 Cookie 文件。不要同时运行来源与目标两个副本来刷新学校课表。

卸载可从 Windows“已安装的应用”、开始菜单“卸载大工课表”或安装管理窗口进入。默认保留课表、备注、设置及登录状态；取消勾选后删除这份安装的数据和专用登录状态，共享登录资料及自行导出的文件保留。迁移会在原数据目录记录登录资料已共享，防止卸载原副本时误清。程序外加的文件不会随发布清单清理。

程序损坏时，解压完整的干净发布包，运行其中的 `Install.cmd` 并点击“安装 / 更新 / 修复”。安装器会使用校验通过的新目录，切换前正常退出原课表，保留原损坏目录及额外文件。反复安装会复用健康副本，上一版本只保留校验通过的目标。同一包在保留额外文件的卸载后也可重新安装，不需先删除这些文件。卸载当前损坏版本前需先修复；已损坏的旧目录会保留，并在结果中说明。

卸载使用 Windows 自带的 Windows PowerShell 5.1，在退出窗口后清理被占用的程序文件，不需要 PowerShell 7；若系统策略禁用此组件，会明确报错。临时目录只留少量清理计划和结果，不复制整套运行库。退出正常课表不会自动启动此清理过程。

首次打开没有课表时，进入设置的“数据与账号”，点击“从学校刷新课表”，在官方学校页面自行登录并进入本科教务课表。必要时在窗口底部确认学号；读取成功后课程出现在桌面，学校浏览器退出。学校刷新需要校园网络可达和 WebView2 Runtime；没有 WebView2 时，仍可离线查看缓存或手动导入 JSON。

课表仅在手动点击后刷新。取消或失败保留现有数据；学校限流时按指定时间等待，到期不自动抓取。校历与节次可在本机调整；扩大周数不会伪造尚未获取的课程数据。个人 JSON 包含课程信息，不含本机校历偏好。

右上四按钮依次为设置、侧边隐藏、悬浮球、Pin。Pin 用于切换固定/允许拖动；S1 正文穿透，解锁后可点课程详情。玻璃透明度在设置中调整。关闭设置只关闭窗口，通用页或系统托盘的“退出程序”才结束当前会话。

固定课表时，正文不响应点击、滚轮、悬停或拖动，可继续操作下面的桌面；只有右上四按钮接收输入。点击 Pin 后可拖动课表并点击课程查看完整名称、地点和冲突信息，再点 Pin 恢复固定。置顶不由 Pin 控制。

侧边隐藏会收成屏幕边缘的小条，停留满一秒展开；离开小条与展开课表的联合区域满一秒收回，短暂离开或重入不会立即收回。边缘方向、条的尺寸和层级在设置中调整；低层条可能被其他窗口遮住，顶层条仍只在可见范围接收输入。设置打开期间暂停自动收回。悬浮球可拖到合适位置；拖动不会误展开，单击恢复之前的课表位置和比例。

系统托盘图标可能位于 Windows 的隐藏图标菜单内；左键恢复课表，右键可进入设置、手动刷新、登录启动开关或明确退出。程序不强制占用托盘主区域。四态都可通过托盘找到设置。

设置的“材质与配色”分别调整背景、前景透明度；课程与导航栏的文字直接显示在统一的半透明表面上。液态边缘强度 0 关闭增强层。若显示异常，可在设置中点击“修复桌面显示”或“重建当前材质”。学校窗口等待时，可在“数据与账号”点“取消学校读取”；取消不会清空已保存课表。

缓存读取失败时会提示只读恢复，并暂时禁用刷新/导入，避免覆盖原文件。可先“导出脱敏诊断”，修复文件后点击“重新读取缓存”。正常课程 JSON 包含个人课程、教师与地点，分享前应自行检查；脱敏诊断只含版本、状态、数量和固定错误码。遇到学校页面错误时无需把密码、验证码或 Cookie 发给他人。

默认个人数据位于 `%LOCALAPPDATA%\DLUTDesktopTimetable`，独立于发布目录。默认目录首次正常启动会按产品设置登记登录启动；可在通用页关闭，关闭后不会因手动重开而恢复。指定 `--data-directory "绝对路径"` 用于隔离验证，不修改真实登录启动项；`--background` 安静读取缓存，不弹空课表设置。

`DlutTimetable.AuthWorker.exe` 是按需启动的独立学校进程，不能手动单独打开。两个 EXE 共用随包运行库，主程序不会因这些文件在目录中而常驻学校浏览器。请保留目录内全部 DLL 与配置文件。

`release-manifest.json` 记录文件散列，ZIP 旁的 SHA-256 校验文件用于检查分发完整性，不等同于发行者数字签名。第三方许可在 licenses 目录。此预览只接受明确标注 dev/preview 的未签名包；正式版本须使用受信任发行者签名的安装器和完整签名包；当前仍为未签名预览。没有后台自动更新；退出不会自动重启。

校外网络可在学校窗口选择“校外 WebVPN 课表”，自行完成学校统一认证或二次验证后进入本人课表。此入口为开发预览，已完成本地集成验证，尚未确认真实校外登录结果；失败或取消会保留已有课程。校园网继续使用“本科教务课表”。
