# 0.26.0-dev · P0 开发预览

给桌面加了一张更好认的周课表，也把最近几轮收尾的细节放进了这一版：

- 今天会在星期栏和日期标记上单独突出。
- Pin 按下/弹起有清楚的颜色状态。
- 缩放档位增加到 0.6–1.2，前景透明度最高可调到 45%。
- 设置页面支持滚动，内容较多时也能完整查看。
- 数据栏与设置栏采用区分开的纯色边框。
- 同一枚低饱和日历图标用于窗口、任务栏和系统托盘。
- 修复 Windows 隐藏系统窗口导致的桌面层级权限错误，避免窗口初始化失败。

## 安装

下载并解压完整 ZIP，然后运行 `DlutTimetable.Desktop.exe`；也可以运行 `Install.cmd` 做当前用户安装。程序自带 .NET 运行库。手动从学校刷新课表需要 WebView2 Runtime 和学校网络。

这是未签名的 Windows 11 x64 开发预览。Windows 登录启动使用当前用户启动项，仍可能受 Windows 设置或组织策略影响。

ZIP 同时附带 `.sha256` 校验文件。
